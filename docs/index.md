# Baton — user documentation

Baton is the small panel that shows you the work a coding agent hands over to you — a
dashboard to open, a key to create, a setting only a person can change — one step at a
time, and tells the agent what happened. It runs on your computer, beside your agent, and
keeps what it sees there.

This is the documentation of the personal Windows build. macOS builds are not available
yet. [Italiano](it/index.md)
