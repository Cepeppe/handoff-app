# Installare Baton su macOS

Le versioni di Baton per macOS **non sono ancora disponibili**. La versione personale è solo
per Windows. È prevista un'app per macOS firmata e autenticata da Apple, e questa pagina ne
descriverà l'installazione — lo spostamento in Applicazioni, il permesso di registrazione
dello schermo, il primo avvio — quando esisterà.

Fino ad allora, [Installare su Windows](install-windows.md) descrive la piattaforma
supportata.
